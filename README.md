# MedEase AI — Clinical Health Assistant & Hospital Navigation

MedEase AI is an AI-powered clinical triage and hospital navigation application designed to help patients understand their symptoms, explore differential health risks, and navigate directly to appropriate medical facilities.

---

## 📱 Implemented Screens & Routes

| Screen | Route | Key Features |
|---|---|---|
| **Home — MediGuide** | `/` | Clinical Intelligence hero, ambient light glow, 5-stage triage pathway sequence, 94.8% accuracy gauge |
| **Health Assessment** | `/assessment` | Intake form, logged symptom chip, conversational follow-up questions with responsive radio tiles, dynamic progress bar |
| **Assessment Result** | `/results` | Differential findings cards, relevance tags, emergency red flags alert, recommended specialty callout |
| **Find Healthcare** | `/find-healthcare` | Interactive Leaflet map with custom pins, telemetry HUD (10 km radius, route traffic), spotlight Best Match card, nearby clinic list |
